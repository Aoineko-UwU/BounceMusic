# Q弹音乐 / BounceMusic

全体保持Q弹！

![Q弹音乐动态展示](assets/readme-animation.gif)

Windows 10/11 x64 便携桌面动画程序，程序通过监听播放设备或受支持系统上的指定应用进程，并根据音频中的节奏驱动自定义图片进行Q弹动画！

纯AI项目，仅供自由使用和参考

## 下载和使用

在 [Releases 发布页](https://github.com/Aoineko-UwU/BounceMusic/releases)下载最新或历史版本的 Windows x64 安装器（`Setup-win64.exe`）或 Portable ZIP。安装版默认安装在当前用户目录，可创建桌面快捷方式并通过 Windows 设置卸载；便携版解压后运行 `BounceMusic.exe`，请保留 `_internal` 文件夹。各版本更新内容见 [更新记录](CHANGELOG.md)。

便携包也保留在仓库的 `packages/` 中，使用 Git LFS 管理；克隆时请先安装 Git LFS 并执行 `git lfs install`，已有克隆可以执行 `git lfs pull`。

Windows 11 上，先播放音乐，点击“自动查找播放进程”，确认选中的进程后点击“开始监听”；也可以手动选择其他进程或播放设备。自动查找会检测活动音频会话，其他正在播放声音的软件也可能被选中。Windows 10 普通客户端版本的单进程捕获接口不可用，程序会选择“播放设备”模式，监听该设备的整体输出音频。主页面可导入图片、调整动画幅度和节奏，并可“刷新 BPM”以重新开始当前音频分析。后台分析 BPM 且检测到音频时，图片右上角显示加载动画；锁定 BPM、暂停或停止音频后消失。

主页面支持自由调整大小，并可打开多个独立图片窗口。“导入图片”可一次选择多张，将文件复制到程序的“图片”文件夹，不会立即更改窗口；点击“选择图片”可选默认图、“玛头”、六张新增预设图或已导入图片，卡片列表支持滚动。右键“我的图片”中的导入图可从程序图片库删除；正在使用该图的窗口会恢复默认图，电脑上的原始文件不受影响。“使用统一图片”让所有窗口显示同一张图；“使用多种图片”时先选中窗口，再选择图片。新建窗口沿用最新窗口的图片，右键图片新建时沿用该图片；没有窗口时使用默认图。升级时会尽量将可用的旧图片复制到图片库。各窗口共用节奏和动画参数，可单独拖动、滚轮缩放及关闭。主页面可勾选“水平翻转动画”，收缩时图像沿 Y 轴向另一面转动，下一次再转回；设置中的“翻转 BPM 阈值”默认为 100 BPM，达到阈值后每压扁两次才翻转一次。双击图片默认快速关闭，可在设置中关闭此行为。右键图片可通过纯文字“更改图像”列表直接切换该窗口的图片，也可打开主菜单或设置、新增 Q弹、刷新 BPM、统一切换置顶或关闭图片；系统托盘菜单也可新增 Q弹。导入图在显示时缩至不超过 900 像素的工作尺寸；同图同尺寸的窗口复用渲染结果，以减少多窗口运行开销。

设置窗口分为“常规、功能、关于”：可调帧率、浅色或深色界面、最高弹跳速度、歌曲结束判定阈值、闪色、BPM 浮动文字、加载动图位置和校准频率等。默认最高弹跳速度为 190 BPM，结束判定阈值为 3.5 秒。锁定闪色默认开启并使用黄色，浮动文字默认使用黄色和黑色描边，可自定义颜色、描边及显示时长；已有用户的设置会保留。主窗口关闭操作可配置为隐藏到托盘、直接退出或每次询问；询问框可勾选“不再询问”。

动画幅度默认 100%，相当于旧版本的 125%；调节范围为 50%–150%。旧设置会换算为新刻度，保持原有弹跳强度。

程序在多次估算一致后锁定 BPM，并根据检测到的强鼓点估计节拍相位；播放期间根据用户选择的低、中、高或自动频率检查 BPM 和节奏对齐，必要时逐步校正。慢歌分析会比较半速与倍速候选，并结合本机积累的相关校准样本；有歧义时可能需要更长观察时间。主页面“手动 BPM”可选择“仅应用”或“应用并学习”，后者会记录当前估算值与输入值用于后续校准；手动 BPM 在歌曲结束后清除。主页面和图片右键菜单可“立即对齐节奏”；若仍觉得动画偏早或偏晚，可用“提前一点 / 延后一点”临时微调，“恢复自动”会清除微调并重新对齐。微调在停止或检测到换曲后清除，不会修改 BPM 学习数据。高速音乐会限制视觉触发频率。节拍层级存在歧义，有歌词的复杂混音、受保护音频和某些播放器仍可能影响识别或捕获。

可选的歌曲结束校准反馈提供五档评价、取消和真实 BPM 输入；也可点击“停止并校准”主动打开。反馈样本保存在本机，可通过“清除学习与对轨数据”重置。指定网易云或 QQ 音乐进程时，若播放器向 Windows 提供媒体会话，程序可使用播放状态和曲目变化辅助判断暂停与换曲；不同播放器版本可能不提供会话，此时回退到静音阈值，无法可靠识别无间隔切歌。播放设备模式也使用静音检测。

## 从源码运行和构建

需要 Windows 10/11 x64、Python 3.12 以及可以访问 PyPI 的网络。PowerShell 中运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python src\app.py
```

构建便携文件夹及安装器：安装 Inno Setup 6 后运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`；便携文件夹和 Setup 位于 `dist/`。只构建便携版可附加 `-SkipInstaller`；编译器不在常见位置时可用 `-InnoCompiler` 指定 `ISCC.exe`。移动便携版时请保留整个文件夹。

运行设置保存在程序目录的 `设置.json`，导入的图片保存在同目录的 `图片` 文件夹；这些个人数据和构建产物不会加入 Git。Portable 包不含个人设置。安装版和便携版均附带面向新用户的 [使用说明.txt](使用说明.txt)。

“设置 → 关于”可检查 GitHub 最新正式版，阅读更新内容后选择更新。便携版下载并校验官方 ZIP 后替换程序文件；安装版下载并校验 Setup 后使用安装器更新。两种方式都会保留设置并重新启动；便携版更新失败时尝试恢复原版本。源码运行模式请手动下载。同一登录会话只允许一个本程序实例运行。

下载时可暂停、继续或中断，中断会清理临时文件。更新包优先通过第三方 ghfast.top 加速，失败或校验不通过时回退 GitHub；版本信息和 SHA-256 校验值仍需从 GitHub 获取。导入非正方形图片时会居中裁剪为 1:1，原文件不变；手动锁定 BPM 后可用“解锁”重新输入或恢复自动分析。

节拍候选分析参考了 [librosa 的节奏分析说明](https://librosa.org/doc/latest/auto_tutorials/01-intro/06-rhythm.html)：结合起音强度和周期性估计速度，再根据节拍位置对齐；本项目针对实时播放和半速/倍速歧义做了轻量实现。
