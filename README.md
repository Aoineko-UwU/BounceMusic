# Q弹音乐 / BounceMusic

全体保持Q弹！

Windows 10/11 x64 便携桌面动画程序，监听播放设备或受支持系统上的指定应用进程，根据音频中的节奏驱动自定义图片进行压扁与回弹。

纯AI项目，仅供自由使用和参考，请谅解

## 下载和使用

`packages/BounceMusic-v1.4.1-win64.zip` 为当前 Windows x64 便携包，解压后运行 `BounceMusic.exe`；请保留 `_internal` 文件夹。仓库使用 Git LFS 管理压缩包，克隆时请先安装 Git LFS 并执行 `git lfs install`；已有克隆可以执行 `git lfs pull`。旧版包保留在 `packages/` 中。

Windows 11 上，网易云音乐可先播放音乐，点击“自动查找网易云”，找到进程后点击“开始监听”；也可以选择其他进程或播放设备。Windows 10 普通客户端版本的单进程捕获接口不可用，程序会选择“播放设备”模式，监听该设备的整体输出音频。主页面可导入图片、调整动画幅度和节奏偏移，并可“刷新 BPM”以重新开始当前音频分析。后台分析 BPM 且检测到音频时，图片右上角显示加载动画；锁定 BPM、暂停或停止音频后消失。

主页面支持自由调整大小，并可打开多个独立图片窗口。“使用统一图片”让所有窗口显示同一张图；“使用多种图片”时新增窗口会提示导入新图，取消选择则使用默认图。各窗口共用节奏和动画参数，可单独拖动、滚轮缩放及关闭。双击图片默认快速关闭，可在设置中关闭此行为。右键图片可打开主菜单或设置、新增 Q弹、刷新 BPM、统一切换置顶或关闭图片；系统托盘菜单也可新增 Q弹。导入图会缩至不超过 900 像素的工作尺寸；同图同尺寸的窗口复用渲染结果，以减少多窗口运行开销。

独立设置窗口包含帧率、BPM 锁定闪色和渐隐时间、最高弹跳速度（默认 150 BPM）、歌曲结束静音阈值（1 至 30 秒）、双击关闭图片及清除学习数据。加载动图的位置可用横向、纵向滑条调整，默认在图片偏右上方；旁边的小窗口会实时预览效果。多图模式下可在设置中选择图片窗口，各窗口分别保存位置；统一图片模式下共用位置。主窗口 X 可配置为隐藏到托盘、直接退出或每次询问；询问框可勾选“不再询问”。设置、校准反馈与关闭询问窗口均居中显示。

程序只使用固定 BPM：在多次估算一致后锁定本首歌曲的 BPM，并根据检测到的强鼓点估计节拍相位；随后按节拍网格弹跳，用后续可信鼓点小幅修正对齐。主页面“手动 BPM”可在音频播放且自动 BPM 已识别后点击“🔒 应用”，以用户实时听感锁定本首歌曲的速度；后台继续对轨，到歌曲结束自动清除。高速音乐会限制视觉触发频率。BPM 可能出现半拍或倍拍；有歌词的复杂混音、受保护音频和某些特殊播放器可能影响识别或捕获。负偏移会按固定网格预测下一个节拍。

可选的 BPM 锁定提示只覆盖图像不透明的区域，可以设置颜色和渐隐时间。可选的歌曲结束校准反馈在达到所设静音时长后弹出，也可点击“停止并校准”主动打开；提供“极差、较差、一般、合适、完美”和“取消”，并可填写音乐软件提供的真实 BPM，或仅提交 BPM。反馈框的 BPM 主要用于积累识别校准样本，主页面 BPM 则立即用于当前歌曲对轨。每首歌曲独立识别 BPM；只有多首歌反馈一致且音频候选节拍接近时，样本才辅助判断半拍/倍拍，不会将同一倍率套用于所有歌曲。单独的主观评级会保留记录，不直接改变算法灵敏度。“清除学习与对轨数据”会重置反馈及校准记录、手动节奏偏移和当前 BPM/相位状态，图片及显示设置保留。静音提示不等同于播放器报告的歌曲结束，也没有读取播放器的曲目信息。

## 从源码运行和构建

需要 Windows 10/11 x64、Python 3.12 以及可以访问 PyPI 的网络。PowerShell 中运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python src\app.py
```

构建便携文件夹：`powershell -ExecutionPolicy Bypass -File .\build.ps1`。输出位于 `dist/BounceMusic`，移动或分发时请保留整个文件夹。

运行设置保存在程序目录的 `设置.json`；该文件、本机图片和构建产物不会加入 Git。Portable 包不含个人设置。
