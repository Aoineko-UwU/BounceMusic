# Q弹音乐 / BounceMusic

全体保持Q弹！

Windows 11 便携桌面动画程序，监听指定应用进程或播放设备，根据音频中的节奏驱动自定义图片进行压扁与回弹。

纯AI项目，仅供自由使用和参考，请谅解

## 下载和使用

`packages/BounceMusic-v1.2.0-win64.zip` 为当前 Windows x64 便携包，解压后运行 `BounceMusic.exe`；请保留 `_internal` 文件夹。仓库使用 Git LFS 管理压缩包，克隆时请先安装 Git LFS 并执行 `git lfs install`；已有克隆可以执行 `git lfs pull`。旧版包保留在 `packages/` 中。

网易云音乐：先播放音乐，点击“自动查找网易云”，找到进程后点击“开始监听”。也可以选择其他进程或播放设备。主页面可切换固定/动态节奏、导入图片、调整动画幅度和节奏偏移，并可“刷新 BPM”以重新开始当前音频分析。

主页面支持多个独立图片窗口。“使用统一图片”让所有窗口显示同一张图；“使用多种图片”时新增窗口会提示导入新图，取消选择则使用默认图。各窗口共用节奏和动画参数，可单独拖动、滚轮缩放、隐藏并从主页面列表恢复。右键图片可打开设置、刷新 BPM、统一取消置顶或关闭该图片显示。

独立设置窗口包含帧率、BPM 锁定闪色和渐隐时间、最高弹跳速度（默认 150 BPM）及清除学习数据。主窗口 X 可配置为隐藏到托盘、直接退出或每次询问；询问框可勾选“不再询问”。

固定 BPM 模式为默认选项。程序在多次估算一致后锁定 BPM，并根据检测到的强鼓点估计节拍相位；随后按节拍网格弹跳，用后续可信鼓点小幅修正对齐。动态模式直接跟随低频和中低频瞬态。高速音乐会限制视觉触发频率。BPM 可能出现半拍或倍拍；有歌词的复杂混音、受保护音频和某些特殊播放器可能影响识别或捕获。负偏移在固定模式下会按网格预测下一个节拍。

可选的 BPM 锁定提示只覆盖图像不透明的区域，可以设置颜色和渐隐时间。可选的歌曲结束反馈以约 5 秒静音作为提示条件，提供“极差、较差、一般、合适、完美”和“取消”；评级用于调整后续节奏瞬态检测的灵敏度，无法单凭评级判断偏早或偏晚。“清除学习与对轨数据”会重置评级记录、灵敏度、手动节奏偏移和当前 BPM/相位状态，图片及显示设置保留。静音提示不等同于播放器报告的歌曲结束，也没有读取播放器的曲目信息。

## 从源码运行和构建

需要 Windows x64、Python 3.12 以及可以访问 PyPI 的网络。PowerShell 中运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python src\app.py
```

构建便携文件夹：`powershell -ExecutionPolicy Bypass -File .\build.ps1`。输出位于 `dist/BounceMusic`，移动或分发时请保留整个文件夹。

运行设置保存在程序目录的 `设置.json`；该文件、本机图片和构建产物不会加入 Git。Portable 包不含个人设置。

## 第三方组件
